# Yichuan Huang Personal Website

Personal website and CV for Yichuan Huang, built with Jekyll and hosted via GitHub Pages.

🔗 **Live site**: [https://yichuan-huang.github.io](https://yichuan-huang.github.io)

## Main Content

- Home page: `_pages/about.md`
- CV page: `_pages/cv.md`
- Publications page: `_pages/publications.md`
- Site configuration: `_config.yml`
- Navigation: `_data/navigation.yml`

## Credits & Acknowledgements

This website is built using the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template, which is itself based on the [Minimal Mistakes Jekyll Theme](https://mmistakes.github.io/minimal-mistakes/) by [Michael Rose](https://github.com/mmistakes).
